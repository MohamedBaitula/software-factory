# AGENTS.md

This repository can be worked on by AI coding agents. Follow these rules unless
the human gives more specific instructions.

## Working Rules

1. Read the assigned goal before changing code.
2. Read `.agents/architecture.md`, `.agents/conventions.md`, `.agents/quality.md`, and `.agents/validation.md` when they exist.
3. Keep changes scoped to the goal.
4. Prefer existing project patterns over new abstractions.
5. Do not modify secrets, credentials, or production deployment settings.
6. Do not run destructive commands.
7. Do not push code automatically.
8. Do not deploy to production.
9. Stop when product behavior is ambiguous.

## Delivery

End with a concise summary of changes, files changed, commands run, results, and
remaining risks.
